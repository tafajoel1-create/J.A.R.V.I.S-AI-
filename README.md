# J.A.R.V.I.S AI

**Just A Rather Very Intelligent System** - A beginner-friendly AI assistant built with Python.

## 📋 Features

- ✅ Natural greeting based on time of day
- ✅ Responds to simple commands
- ✅ Time and date queries
- ✅ Help menu
- ✅ Easy to expand with new features

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/tafajoel1-create/J.A.R.V.I.S-AI-.git
cd J.A.R.V.I.S-AI-
```

2. **Install dependencies** (optional for now)
```bash
pip install -r requirements.txt
```

3. **Run the program**
```bash
python main.py
```

## 💬 How to Use

Once the program runs, you can chat with J.A.R.V.I.S:

```
Try saying:
- "Hello" or "Hi"
- "What is your name?"
- "What time is it?"
- "What is today's date?"
- "Help"
- Type "exit" to quit
```

## 🔧 What's Inside

### main.py
- `greet_user()` - Greets based on time of day
- `get_response()` - Processes user input and generates responses
- `main()` - Main program loop

### config.py
- Stores configuration settings
- Easy place to manage AI behavior

### requirements.txt
- Lists all Python libraries needed
- Can be expanded as we add features
